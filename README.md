# Dynamic-Programming

### Learn by pattern
Try to look for pattern in the problem, this can only come with practice.

* 1D linear: climbing stairs, house robber, coin change
* 2D grid: unique paths, min path sum
* Knapsack: 0/1 knapsack, subset sum, partition
* Two sequences: longest common subsequence, edit distance
* Interval: matrix chain, burst balloons
* Bitmask / state machine: TSP, stock buying with cooldown

Usually tho, it is asking to find the most optimal way to solve something
